# Merge Sort and Multithreaded Merge Sort

## Mini Project – Design and Analysis of Algorithms (DAA)

This project is developed as a **Mini Project for Final Year Computer Engineering – Semester 7** as part of the **LP3 Lab Manual** for the subject **Design and Analysis of Algorithms (DAA)**.

### About the Project

The project implements and compares two versions of the Merge Sort algorithm:

- **Normal Merge Sort**
- **Multithreaded Merge Sort**

The execution time of both algorithms is measured and compared for the given input. The project also demonstrates the time complexity of Merge Sort in different cases.

### Time Complexity

- Best Case: **O(n log n)**
- Average Case: **O(n log n)**
- Worst Case: **O(n log n)**

### Technology Used

- **Python**
- **Multithreading**

This project demonstrates the application of **Divide and Conquer** and **Multithreading** concepts in algorithm design.
